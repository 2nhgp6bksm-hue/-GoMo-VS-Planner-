GoMo VS Planner v2.3 — GitHub Pages

CORRECTION PRINCIPALE
- Les camions commerciaux UR sont maintenant limités à 5 par jour.
- Le calculateur ne peut plus proposer 30 camions lorsque le stock contient plusieurs milliers d’unités.
- Dès que les 5 camions sont utilisés dans le plan, le calcul passe automatiquement aux autres ressources disponibles du jour.
- Les boutons Diminuer/Augmenter respectent également cette limite.

INSTALLATION
Décompressez l’archive puis remplacez les fichiers à la racine du dépôt GitHub Pages.
Validez avec « Commit changes », puis actualisez le site.

GoMo VS Planner v2.2 — Mode ultra simple

NOUVEAUTÉS
- Écran principal réduit à 3 étapes : vérifier le jour, ajouter les captures, suivre le plan.
- La lecture OCR et le calcul démarrent automatiquement après l'ajout des captures.
- Le plan affiche une liste très claire et numérotée des ressources à utiliser.
- Gros bouton « J’ai utilisé ces ressources » après l’exécution du plan.
- Les profils de points, le score manuel, la relance OCR et les ajustements sont cachés dans des options facultatives.
- Le mode manuel complet, le guide et les réglages restent disponibles.
- Les corrections OCR de la v2.1 sont conservées.

Installation GitHub Pages
1. Décompresser l’archive.
2. Envoyer tous les fichiers à la racine du dépôt.
3. Remplacer les anciens fichiers puis attendre la mise à jour de GitHub Pages.
4. Sur iPhone, fermer puis rouvrir le raccourci. Si l’ancienne version reste affichée, actualiser la page une fois.

Nouveautés v2.4 :
- valeurs des jours 1 à 6 relevées sur les captures du Duel d’alliances ;
- doublons retirés dans chaque journée ;
- profil de points vérifié sélectionné automatiquement ;
