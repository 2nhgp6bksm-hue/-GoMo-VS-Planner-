GoMo VS Planner v2.0 — Assistant automatique simplifié

NOUVEAU
- Les captures sont lues et appliquées automatiquement.
- Le programme choisit lui-même les ressources et les quantités pour atteindre 7,2 M avec la marge.
- Plus de liste compliquée à vérifier dans le mode Assistant.
- Pour chaque ressource proposée : Ne pas utiliser, Diminuer, Garder ou Augmenter.
- Dès qu’un choix change, le reste du plan est recalculé automatiquement pour rester au plus près de l’objectif.
- Un seul bouton permet d’accepter le plan et de déduire les ressources.
- Le récapitulatif plein écran pour capture d’écran reste disponible.

La saisie manuelle et les réglages avancés restent accessibles dans l’onglet « Saisie manuelle ».

Installation GitHub Pages
1. Décompresser l’archive.
2. Envoyer tous les fichiers à la racine du dépôt.
3. Remplacer les anciens fichiers puis attendre la mise à jour de GitHub Pages.
4. Sur iPhone, actualiser la page ; si nécessaire fermer puis rouvrir le raccourci.
