GoMo VS Planner v1.4 — Calcul automatique ajustable

Nouveautés :
1. Le site calcule automatiquement les ressources utiles du jour avec les valeurs de base du jeu.
2. Le bonus de recherche VS est appliqué automatiquement au calcul.
3. Chaque quantité du plan peut être diminuée ou augmentée avec les boutons – / +, ou saisie directement.
4. À chaque modification, les autres ressources sont recalculées immédiatement pour viser au minimum 7,2 millions de points avec la marge choisie.
5. Une ressource peut être désactivée avec « Ne pas utiliser », puis réactivée.
6. Le bouton « Revenir au calcul automatique » efface les choix manuels du jour.
7. Les stocks, réserves et valeurs personnalisées restent conservés dans le navigateur.

La saisie par captures, la saisie manuelle, les sept langues et le fonctionnement hors ligne sont conservés.

Langues : français, anglais, allemand, roumain, ukrainien, coréen et croate.
Hébergement : GitHub Pages, sans crédit d’utilisation.
Données : conservées uniquement dans le navigateur de l’appareil.
OCR : la première lecture nécessite Internet pour charger Tesseract.js. Les images ne sont pas envoyées dans une base de données.
